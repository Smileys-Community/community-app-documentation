# Feature Requirements — Public Discovery (MVP)

## Goals
Enable non-logged-in exploration to drive signups and RSVPs.

## Acceptance Criteria
- Landing page: hero, featured groups, upcoming events, social links, legal links.
- Groups directory: list with pagination; text search by name.
- Events directory: upcoming filter by date; text search by title/city.
- Event detail: map (embed or Maps URL), OG/Twitter metadata, “RSVP/Login” CTA.

## Performance & SEO
- Fast LCP on mobile; valid OG cards; sitemap for groups/events.
