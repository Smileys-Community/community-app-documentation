# 03 — Feature Requirement Documents (FRDs)
**Purpose**: Detail each major feature.  
**Inputs**: PRD.  
**Outputs**: One FRD per feature with flows & acceptance tests.

## Checklist (per feature)
- Problem & goal
- User scenarios and flows (incl. edge cases)
- Acceptance criteria & test cases
- Data captured & privacy notes
- Performance/SLO & accessibility notes
- Analytics events

**Definition of Done**: Features sliceable into tickets with clear ACs.

### AI Prompt
As a product/QA duo, create an FRD for the feature **"{{feature name}}"**.  
Provide: problem/goal, in-scope/out-of-scope, user scenarios, detailed flow(s), acceptance criteria (Given/When/Then), error/empty states, performance & accessibility requirements, data model notes, analytics events (name, props), and test cases. Format as Markdown.
