# 08 — Delivery Plan & Roadmap
**Purpose**: Timebox MVP and sequence work.  
**Inputs**: PRD, tech docs.  
**Outputs**: Milestones, critical path, risk register, release plan.

## Checklist
- 12-week MVP plan (sprints/milestones)
- Critical path & dependencies
- Scope by increment
- Risk register with owners/mitigations
- Beta → GA release strategy

**Definition of Done**: Plan agreed by PM/TL/Program.

### AI Prompt
You are a program manager. Build a 12-week MVP roadmap for **{{product}}**.  
Include: milestones by sprint, scope by increment, dependencies, resource plan, risk register (probability/impact/mitigation/owner), and a phased rollout plan (beta→GA) with entry/exit gates. Return as Markdown with a milestone table.
