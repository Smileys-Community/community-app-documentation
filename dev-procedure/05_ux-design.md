# 05 — UX Design
**Purpose**: Produce IA, wireframes, prototype.  
**Inputs**: Research artifacts, PRD/FRDs.  
**Outputs**: IA, low/high-fi wires, clickable prototype, design tokens.

## Checklist
- Information architecture (sitemap, key objects)
- Low-fi wireframes of critical paths
- High-fi for the “first 15 minutes”
- Clickable prototype
- Design tokens (colors/typography/spacing)
- Accessibility annotations

**Definition of Done**: Prototype validates key tasks with 5–8 users.

### AI Prompt
You are a senior product designer. Create a UX spec for **{{feature/app}}**.  
Deliver: IA (list of objects and relationships), low-fi wireframe descriptions for **{{critical tasks}}**, high-fi spec for key screens (with components/states), accessibility notes (WCAG 2.2 AA targets), and a design token starter set. Provide a prototype narrative (steps users take). Output in Markdown with screen-by-screen sections.
